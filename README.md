# Crank Mechanism Simulation

A Unity-based mechanical articulation project demonstrating a crankshaft-style mechanism using **Hinge Joints** and motor-driven motion.

## Overview

The project was developed in Unity on Ubuntu/Linux to study mechanical articulation and real-time motion using Unity's physics system.

The mechanism consists of articulated components connected through joints, with motor-driven movement used to produce continuous mechanical motion.

## Key Concepts

* Hinge Joint articulation
* Motor-driven rotation
* Mechanical linkage motion
* Unity physics
* Real-time articulation and constraints

## Tools

* Unity
* C#
* Ubuntu/Linux

## Purpose

The project was created to understand how articulated mechanical systems can be simulated using physics-based joints and motor constraints in Unity.

## Files

The repository contains the Unity project files and related assets used for the simulation.
